# Para-o-meu-amor-
Sobre o projeto: Desenvolvido como um projeto pessoal e criativo, unindo desenvolvimento front-end a um propósito afetivo — presentear alguém especial com uma experiência digital única, ao mesmo tempo em que serviu como exercício prático de HTML, CSS e JavaScript puro (manipulação do DOM, animações, responsividade e lógica de interação).
